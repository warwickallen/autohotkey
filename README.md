# AutoHotkey

AutoHotkey scripts for Windows automation.

## Getting Started

1. Install AutoHotkey from the official website:
   - https://www.autohotkey.com/
2. Place `.ahk` files in a folder of your choice.
3. Double-click a `.ahk` file to run it.
4. To stop a running script, right-click the AutoHotkey icon in the system tray
   and choose `Exit`.

## Scripts in This Repo

- [**CapsLock-Tab-LeftShift**.ahk]  
  - Caps Lock → Tab
  - Hold Left Shift for 5 seconds → Caps Lock

  Useful for keyboards with a broken or missing tab key.

## Automatic Start-Up

To automatically start the script when logging in, place a shortcut to the
script in
`%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`.
## Editing Scripts

- Open `.ahk` files in a text editor.
- Save changes and then reload the script by right-clicking the tray icon and
  selecting `Reload Script`.
